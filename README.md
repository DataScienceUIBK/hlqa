# HLQA Tutorial: Human-in-the-Loop Question Answering

This repository contains open materials for the tutorial **HLQA: Human-in-the-Loop Question Answering**.

HLQA is a design perspective that reframes question answering from direct answer delivery into an adaptive collaborative reasoning process. The tutorial focuses on three complementary mechanisms:

1. **Adaptive Questioning** — Socratic and adaptive questions that stimulate reasoning.
2. **Hint Generation** — progressively informative guidance for intermediate reasoning steps.
3. **Explanation Generation** — explanations that consolidate understanding and reflection.

## Repository Contents

- `index.html` — GitHub Pages landing page.
- `syllabus.md` — tutorial outline and schedule.
- `reading_list.md` — suggested readings grouped by topic.
- `demos/` — links and descriptions of interactive demos.
- `notebooks/` — notebook placeholders for hands-on examples.
- `slides/` — slides will be uploaded after the tutorial.
- `resources/` — BibTeX and additional references.
