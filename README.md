# HLQA Tutorial Repository

Structured repository for the HLQA tutorial webpage.

## Structure

- `docs/index.html` - main webpage entrypoint
- `assets/css/styles.css` - stylesheet
- `assets/js/main.js` - interactive behavior
- `LICENSE` - license file

## Notes

- Content is derived from the attached LaTeX/Bib references, but those source files are intentionally not stored in this repository.
- For GitHub Pages, set the publishing source to the `/docs` folder on the default branch.
